                     DANH SÁCH ĐƯỜNG DẪN DỰ ÁN (PROJECT PATHS)

1. WEB ROUTES (Giao diện người dùng)
--------------------------------------------------------------------------------
- Trang chủ (Home):
  URL: /
  File: src/app/page.tsx

- Trang Đăng nhập (Login):
  URL: /login
  File: src/app/login/page.tsx

- Trang Đăng ký (Register):
  URL: /register
  File: src/app/register/page.tsx

- Trang Chi tiết Dịch vụ (Service Dynamic Detail):
  URL: /dichvu/{id} (ví dụ: /dichvu/1)
  File: src/app/dichvu/[id]/page.tsx

- Trang Not Found (404):
  URL: /_not-found
  File: Next.js default / Custom error handler


2. API ROUTES (Endpoints xử lý dữ liệu)
--------------------------------------------------------------------------------
- Đăng nhập (Auth Login):
  URL: /api/auth/login
  Method: POST
  File: src/app/api/auth/login/route.ts
  Mô tả: Xác thực tài khoản người dùng qua Email hoặc Số điện thoại, kiểm tra mật khẩu (bcrypt), tạo session cookie.
  Body (JSON):
    {
      "identifier": "string (email hoặc số điện thoại)",
      "password": "string",
      "rememberMe": boolean (optional)
    }

- Đăng ký (Auth Register):
  URL: /api/auth/register
  Method: POST
  File: src/app/api/auth/register/route.ts
  Mô tả: Đăng ký tài khoản mới với Số điện thoại (bắt buộc), Ngày sinh (bắt buộc), Mật khẩu (bắt buộc), Email (tùy chọn), lưu vào MySQL qua Prisma với id tự tăng (autoincrement).
  Body (JSON):
    {
      "phone": "string (bắt buộc, số điện thoại)",
      "password": "string (bắt buộc, tối thiểu 6 ký tự)",
      "dateOfBirth": "string (bắt buộc, YYYY-MM-DD)",
      "email": "string | null (tùy chọn, optional)",
      "fullName": "string (tùy chọn)"
    }

- Chi tiết Dịch vụ (Get Service Detail):
  URL: /api/dich-vu/[id]
  Method: GET
  File: src/app/api/dich-vu/[id]/route.ts
  Mô tả: Lấy thông tin chi tiết dịch vụ vệ sinh (bảng giá, mô tả, checklist công việc, thông tin gian hàng/shop) từ bảng `DichVu`.

- Lấy thông tin người dùng hiện tại (Get Current User Session):
  URL: /api/auth/me
  Method: GET
  File: src/app/api/auth/me/route.ts
  Mô tả: Kiểm tra cookie phiên đăng nhập và trả về thông tin người dùng đang đăng nhập (hoặc unauthenticated nếu chưa đăng nhập).

- Đăng xuất (Auth Logout):
  URL: /api/auth/logout
  Method: POST
  File: src/app/api/auth/logout/route.ts
  Mô tả: Xóa cookie phiên đăng nhập `cleanmate_session` trên trình duyệt.
